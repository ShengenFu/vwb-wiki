# VWB Wiki

Öffentlicher, deutschsprachiger Onboarding-Wegweiser für das Institut für Verkehrswegebau an der TU Darmstadt.

## Veröffentlichung mit GitHub Pages

In den Repository-Einstellungen unter **Pages** die Quelle **Deploy from a branch**, den Branch **main** und den Ordner **/(root)** wählen. Die Website benötigt keinen Build und keine zusätzlichen Abhängigkeiten.

## Inhalte bearbeiten

- `app.js`: Artikel, Onboarding-Aufgaben, Kontaktwegweiser und Quellen.
- `style.css`: Layout und Gestaltung.
- `index.html`: Grundstruktur und Metadaten.

Änderungen auf dem veröffentlichten Branch werden durch GitHub Pages bereitgestellt. Die Aufgabenliste speichert den persönlichen Fortschritt ausschließlich im Browser. Gemeinsame Online-Bearbeitung und zentrale Konten sind nicht implementiert.

## Alternativ: Render

Eine **Static Site** mit diesem Repository verbinden. Publish Directory: `.`. Build Command: `echo "Static site ready"`. Keine Umgebungsvariablen erforderlich.

## Redaktion

Öffentliche Quellen sind in der Website verlinkt. Institutsinterne Abläufe sind als Vorschlag oder noch zu bestätigen gekennzeichnet. Vor dem institutionellen Einsatz Verantwortlichkeiten, Prozesse und Vorlagen fachlich freigeben.
